# Belajar PAI — Bahan Ajar Interaktif Moderasi Beragama

Website bahan ajar interaktif Pendidikan Agama Islam (PAI) yang dirancang untuk membantu siswa memahami materi moderasi beragama secara lebih menarik dan interaktif.

## 📚 Materi Pembelajaran

Website ini memuat materi:
- Toleransi
- Q.S. Yunus 10:40–41
- Q.S. Al-Mā'idah 5:32

## ✨ Fitur

- 🏠 Beranda
- 📖 Materi Pembelajaran
- ✨ Aktivitas Pembelajaran
- 📝 Pengumpulan Hasil Aktivitas
- 📊 Penyimpanan hasil aktivitas menggunakan Google Sheets
- 🎯 Evaluasi/Kuis
- 💭 Refleksi
- 📌 Rangkuman Materi

## 🛠️ Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- Tailwind CSS
- Lucide Icons
- Google Apps Script
- Google Sheets

## 🎯 Tujuan

Website ini dikembangkan sebagai bahan ajar interaktif untuk mendukung proses pembelajaran PAI, khususnya dalam memahami nilai toleransi dan moderasi beragama dalam kehidupan sehari-hari.
